------------
INTRODUCTION
------------

The mission generation is accomplished through the use of the code present in the folder MissionGenCode. This code is present in every folder generating different missions for different tests. 

-----------
EXPLANATION
-----------

For creating a function, the following variables must be set:

MissionName - string containing the mission name.
time - vector containing time breakpoint values in seconds;
ThrustRef - vector containing thrust command breakpoint values in Newton;
Alt - vector containing altitude breakpoint values in meters;
MN - vector containing flight Mach number breakpoint values;
EngineCommand - vector containing time breakpoint values;

For all vectors, except the EngineCommand, each set of two points is used to form a straight line with the corresponding points of time vector. This way, curves of altitude, Mach number, thrust command of any shape can be accurately describe in order to reproduce realistic missions in either simulation or test bench. For example, for the time vector time = [0 2] and the Alt =  [0 1000], the altitude will vary in straight line from 0 to 1000 m from the instants 0 to 2 s. In the case of EngineCommand, the value will be set at the corresponding instant and remain fixed until further change is identified in the command vector. 

After all vectros are defined, the command line below must be executed:

MissionGenCols(Alt,MN,ThrustRef,EngineCommand,time,MissionName);

With this command line being executed, a .xlsx file will be generated for automatic execution by simulation or real test.

-------
EXAMPLE
-------

Example 1 - TestBench folder

In this folder, simpler missions for testing engine response at engine test bench are generated with the help of a simulink model. An additional script called MissionBlocks.m has been written in order for setting the right values of altitude, Mach number and ambient temperature and also calling the function MissionGenCols for generating the mission file. The code is written as follows:

------------------------------------------------------------------------

Simout = sim('Mission_Visit_2023_08_09','ReturnWorkspaceOutputs','on');

time = Simout.simout.time;
ThrustRef = Simout.simout.data;
Alt = 567 * ones(1,length(time));
MN = 0 * ones(1,length(time));
EngineCommand = 170 * ones(1,length(time));
EngineCommand(end) = 0;
MissionName = 'MissionTB_001';

MissionGenCols(Alt,MN,ThrustRef,EngineCommand,time,MissionName);

--------------------------------------------------------------------------

The firsrt line executes the simulink model which generates the ouputs of time and thrust vectors. Altitude is set to a fixed value, corresponding to a static test at the given altitude. Mach number vector is also set to zero, corresponding to static test. Engine command is set to 170, corresponding to engine start, with the last value set to 0, which is the Shut off command. The mmission name is defined as MissionTB_001. Finally, in the last line, the code for generatin the .xlsx file is executed
